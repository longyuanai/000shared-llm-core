# shared-llm-core v0.1 接口契约（冻结）

> **冻结日期**: 2026-07-24
> **冻结版本**: shared-llm-core 0.1.0
> **适用范围**: 7 个 AI 安全 Agent 产品的所有 v0.1 / v1.0 阶段

本文件是 **shared-llm-core** 的对外 API 契约。**v0.1 阶段不再 breaking-change**——只能加字段，不能改/删字段。新增字段必须向后兼容。

---

## 1. 顶层导出（stable）

```python
from shared_llm_core import (
    # 配置 & 路由
    LLMRouter,            # 主入口：tier → provider+model
    RouteRule,            # 一条路由规则
    TaskTier,             # 任务等级

    # 请求 / 响应
    ChatRequest,          # 入参
    ChatResponse,         # 出参
    ChatChoice,           # 响应中的一条 choice
    ChatMessage,          # 一条消息
    ChatUsage,            # token 用量

    # 客户端
    LLMClient,            # 单 provider 客户端

    # 模板
    PromptTemplate,       # 单个版本化 prompt
    TemplateRegistry,     # 模板注册中心

    # 审计
    AuditLog,             # JSONL 审计日志
    AuditRecord,          # 一条审计记录

    # 元信息
    __version__,          # "0.1.0"
)
```

**承诺**：上述所有符号在 v0.1 / v0.5 / v1.0 阶段都存在。改名 / 移除 = breaking change。

## 2. 数据类型（frozen schema）

### 2.1 `TaskTier`

```python
class TaskTier(str, Enum):
    CHEAP    = "cheap"      # 分类、路由、单行答案
    STANDARD = "standard"   # 摘要、叙述、解释
    PREMIUM  = "premium"    # 复杂推理、多步 Agent
    LOCAL    = "local"      # 强制本地 provider（忽略其他 tier）
```

**何时用哪个**：

| Tier | 典型场景 | 推荐模型 |
|------|---------|---------|
| `CHEAP` | 6 类攻击分类、SSH 日志单行评分 | Haiku / Qwen2.5-1.5B |
| `STANDARD` | 漏洞叙述、富化、Markdown 摘要 | Sonnet / Qwen2.5-7B |
| `PREMIUM` | 二进制反编译、复杂推理、Agent 决策 | Opus / Qwen2.5-72B |
| `LOCAL` | 数据不出域时强制本地 | 任意本地模型 |

### 2.2 `ChatMessage`

```python
class ChatMessage(BaseModel):
    role: str                              # "system" | "user" | "assistant" | "tool"
    content: str
    name: str | None = None
    tool_call_id: str | None = None
```

冻结。`role` 限定 4 个值，不允许 `function`（那是 OpenAI 旧版）。

### 2.3 `ChatRequest`

```python
class ChatRequest(BaseModel):
    model: str | None = None              # 不填则用 router 选定的
    messages: list[ChatMessage]
    temperature: float = 0.2              # 0.0 - 2.0
    max_tokens: int | None = None
    top_p: float = 1.0                    # 0.0 - 1.0
    response_format: dict[str, str] | None = None    # {"type": "json_object"}
    tools: list[dict[str, Any]] | None = None
    tool_choice: str | dict[str, Any] | None = None
    stop: list[str] | None = None
    request_id: str = <auto-uuid>         # 自动生成，用于审计追踪
    extra: dict[str, Any] = {}            # 透传给上游 provider 的私有字段
```

**冻结承诺**：
- 所有字段可读、可写
- `extra` 永远不会被 shared-llm-core 自己读，传给上游即可
- `request_id` 默认自动生成，业务方不要手动指定

### 2.7 `RouteRule`

```python
@dataclass(frozen=True)
class RouteRule:
    tier: TaskTier
    provider: str       # provider 配置名（"local" / "openai" / "anthropic" / ...）
    model: str          # 模型名（"qwen2.5-7b" / "claude-sonnet-4-6" / ...）
```

### 2.8 `LLMRouter`

```python
class LLMRouter:
    def __init__(self, cfg: CoreConfig, rules: list[RouteRule], audit: AuditLog | None = None) -> None

    @classmethod
    def from_env(cls, rules: list[RouteRule] | None = None, yaml_path: str | None = None) -> "LLMRouter": ...

    def close(self) -> None: ...
    def __enter__(self) -> "LLMRouter": ...
    def __exit__(self, *_: object) -> None: ...

    def resolve(self, tier: TaskTier) -> tuple[LLMClient, str]: ...
    def chat(self, tier: TaskTier, req: ChatRequest) -> ChatResponse: ...
```

**核心方法签名冻结**。`chat(tier, req)` 是所有 7 个产品的统一入口。

### 2.9 `LLMClient`

```python
@dataclass
class LLMClient:
    provider: ProviderConfig
    _http: httpx.Client                    # 内部

    def __post_init__(self) -> None: ...
    def close(self) -> None: ...
    def __enter__(self) -> "LLMClient": ...
    def __exit__(self, *_: Any) -> None: ...

    @retry(stop=stop_after_attempt(3), wait=wait_exponential(multiplier=0.5, min=0.5, max=4.0))
    def chat(self, req: ChatRequest) -> ChatResponse: ...

    def stream(self, req: ChatRequest) -> Iterator[str]: ...
```

**重试策略冻结**：3 次重试，指数退避 0.5s → 4s。这是契约的一部分。

class PromptTemplate:

### 2.11 `TemplateRegistry`

```python
class TemplateRegistry:
    def __init__(self, root: str | Path) -> None: ...
    def get(self, name: str, version: str = "latest") -> PromptTemplate: ...
```

**目录布局冻结**：
```
prompts/
└── <template-name>/
    ├── 1.0.0.yml
    ├── 1.1.0.yml
    └── 2.0.0.yml
```

文件名 = 版本号，`get(name, "latest")` 取字典序最大的。

### 2.12 `AuditLog`

```python
@dataclass
class AuditLog:
    cfg: AuditConfig

    def record(self, *, request: ChatRequest, response: ChatResponse, provider: str, latency_ms: int) -> None: ...
```

**审计落盘格式**：JSONL，每行一条 `AuditRecord`。文件路径由 `AuditConfig.path` 决定。

### 2.13 `AuditRecord`

```python
@dataclass
class AuditRecord:
    request_id: str
    ts: datetime
    provider: str
    model: str
    tier: TaskTier | None
    prompt_tokens: int
    completion_tokens: int
    total_tokens: int
    latency_ms: int
    request: ChatRequest
    response: ChatResponse
```

冻结。所有字段必现，方便外部审计系统解析。

## 3. 配置文件 schema（冻结）

### 3.1 YAML 结构

```yaml
providers:
  local:
    type: openai_compat
    base_url: http://localhost:8000/v1
    api_key: sk-no-auth-needed
    default_model: qwen2.5-7b-instruct
    enabled: true
    timeout_s: 30
  openai:
    type: openai_compat
    base_url: https://api.openai.com/v1
    api_key: ${OPENAI_API_KEY}    # 环境变量插值
    default_model: gpt-4o-mini
    enabled: true
    timeout_s: 30

audit:
  backend: jsonl
  path: ./audit.jsonl

routing:
  - tier: cheap
    provider: local
    model: qwen2.5-1.5b-instruct
  - tier: standard
    provider: local
    model: qwen2.5-7b-instruct
  - tier: premium
    provider: openai
    model: gpt-4o
```

**冻结承诺**：
- `providers` 字典的 key 是 provider 名
- `type: openai_compat` 是 v0.1 唯一支持的类型（v0.5 可能加 `anthropic_native`）
- 环境变量 `${VAR_NAME}` 语法冻结
- `routing` 列表中每项的 3 个字段（tier / provider / model）冻结

## 4. 行为契约（frozen behavior）

### 4.1 路由行为

- `router.chat(tier, req)` 必须按 `tier` 找到对应 `RouteRule`，并把 `req.model` 填上
- 找不到 tier → `KeyError`
- 找不到 provider → `KeyError`
- 上游 4xx/5xx → tenacity 重试 3 次 → 抛 `httpx.HTTPStatusError`
- 网络错误 → tenacity 重试 3 次 → 抛 `httpx.RequestError`

### 4.2 审计行为

- 每次 `router.chat()` 调用 **必须** 写一条 `AuditRecord`（除非 `audit=None`）
- `latency_ms` 必须包含 client.chat 本身的耗时（不含 router 解析）
- 写审计失败 **不影响** chat 返回值（错误被吞，stderr 警告）

### 4.3 模板行为

- `registry.get(name, "latest")` 字典序最大
- 渲染用 Jinja2 `StrictUndefined`——模板中未传的变量直接抛错
- 模板缓存到内存（`_cache` dict），不自动重载

### 4.4 客户端行为

- `LLMClient.chat()` 永远 retries 3 次
- `LLMClient.stream()` **不** retries（流式半成品无意义）
- JSON mode 通过 `response_format={"type": "json_object"}` 走标准 OpenAI 协议

## 6. 版本演进规则

| 阶段 | 允许的变更 |
|------|-----------|
| **0.1.x** | 仅 patch：bug fix、文档、测试加固。**不允许** 改 schema |
| **0.5.x** | minor：可加新字段（默认 None）、可加新方法。**不允许** 改/删现有字段或方法签名 |
| **1.0.x** | 同 0.5 |
| **2.0.x** | 允许 breaking change，但必须写迁移指南 |

**语义版本控制**，从 0.1.0 → 1.0.0 由 7 个项目全部 v1.0 上线触发。

## 7. 已知约束（v0.1 不解决）

- 不支持 Anthropic native API（必须经 OpenAI 兼容代理）
- 不支持 function calling 的 stream 模式
- 不支持 multi-modal（图像、音频）
- 不支持 batch API
- 审计日志不自动 rotate（外部工具负责）
- 单进程内的 router 是 thread-safe，但 `LLMClient._http` 不保证跨进程安全

v0.5 计划解决部分，v1.0 解决全部。
