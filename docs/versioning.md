# 套件版本策略

shared-llm-core 与各产品仓采用以下版本约定：

1. shared-llm-core 的包版本等于它实现的最高契约版本。当前实现包含 v0.6 §15，
   因此版本为 `0.6.0`。
2. 产品仓各自遵循 SemVer 独立演进，不与 shared-llm-core 强制对齐。
3. 部署组合仍以 `suite-lock.yml` 中各仓的精确 Git SHA 为事实源；版本号服务于人类
   识别与未来的包分发，不承担部署锁定职责。
4. 本次只调整 shared-llm-core。integration 与各产品仓维持既有版本，避免制造
   无意义的同步版本变更。

shared-llm-core 的对外签名发生变化前，必须先写 ADR 说明兼容性、迁移影响与回滚方案，
并至少提升次版本号；破坏兼容性的稳定版变更按 SemVer 提升主版本号。冻结契约仍按其
原始版本保留，新增契约能力以加法方式进入后续版本。
