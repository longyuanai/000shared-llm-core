## 2. 任务(Issues)

### Issue 007-CI-001 · 单仓 workflow(.github/workflows/inspect.yml)

**位置**:根目录 `E:\001项目\000开发\003AI+网络安全\.github\workflows\inspect.yml`(新建,因为是 mono-ish 仓库)

**内容骨架**:

```yaml
name: inspect-worker-return

on:
  pull_request:
    paths:
      - "001AI-SOC-Agent/**"
      - "002AI-Vulnerability-Agent/**"
      - "003AI Agent安全靶场/**"
      - "004AI代码审计/**"
      - "005AI逆向Agent/**"
      - "006AI-Firmware-Security-Agent/**"
      - "scripts/inspect_worker_return.py"
  push:
    branches: [main]

jobs:
  inspect:
    runs-on: windows-latest  # 因为产品 CLI 是 Python + Windows 中文路径
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 10  # 够 inspect 跑 git log --oneline -5

      - name: Setup Python 3.14
        uses: actions/setup-python@v5
        with:
          python-version: "3.14"

      - name: Install project deps
        shell: pwsh
        run: |
          $py = "C:\hostedtoolcache\windows\Python\3.14*\x64\python.exe"
          Get-ChildItem $py | Select-Object -First 1
          # 每个产品 install(用 002/003/004/005/006 的实际包名)
          # 不在这里展开——Codex 写时按各仓 README 装

      - name: Run inspect (6 workers)
        shell: pwsh
        run: |
          $py = (Get-Command python).Source  # 取出 actions/setup-python 配的
          & $py scripts/inspect_worker_return.py
        env:
          PYTHONPATH: ${{ env.PYTHONPATH }}
```

**要点**:
- 单仓 workflow 跑全 6 worker(mono 仓假设),简化
- 用 `windows-latest`(因为 Windows 中文路径坑只能用 Windows runner 验证)
- Python 版本与 6 worker `pyproject.toml` 一致
- 不接 `IntegrationGateway`(它还没 docker 化,接入会让 CI 变脆)
- 跑 ≥ 5 分钟 timeout(`inspect_worker_return.py` 现状可能要 5+ 分钟跑完 6 worker)

### Issue 007-CI-003 · §3 已知坑进 workflow(step 顺序锁)

**为什么**:Windows Python 3.14 + 中文路径 + pytest 的 WinError 5 在 GH Actions runner 上**同样会触发**(CLAUDE.md §3.1)。

**强制**:

workflow 文件**必须**包含:

```yaml
- name: Run pytest (per worker)
  shell: pwsh
  run: |
    $pp = "001AI-SOC-Agent/src"  # 按 worker 改
    $py = (Get-Command python).Source
    & $py -m pytest $pp/../tests/ `
      --basetemp=C:/pytest-tmp/ `
      -o addopts= `
      -q --tb=no
  working-directory: 001AI-SOC-Agent
  env:
    PYTHONPATH: $pp
```

**缺 `-o addopts=` → CI 在 Windows runner 上 WinError 5 → 全错**。

Codex 写 workflow 时**必须**逐 worker 配这段,不能只写在主 step。

## 3. 测试(Tests)

- workflow yaml 用 `act` 或者 GitHub Actions 调试工具 dry-run 验过
- 用 `workflow_run` 触发测试 workflow(先 push 一个空 commit 到测试分支,看 Actions 跑没跑)

**注意**:真 GH Actions 没法本地 run 完整,只能:
1. YAML lint(`actionlint`)
2. 推到测试分支验
3. 看 step log

## 5. 约束(Constraints)

**禁止**:
- ❌ 改 `scripts/inspect_worker_return.py` 的核心逻辑(只允许加 `--markdown-summary` flag,**不**改 4 件套语义)

- ✅ `--basetemp=C:/pytest-tmp/` + `-o addopts=` 在每个 worker pytest step 都显式
- ✅ Python 用绝对路径 `(Get-Command python).Source` 取出,**不**写 `python`
- ✅ workflow 用 `windows-latest` runner
- ✅ 6 worker 全部覆盖(可以串行 step,不必 matrix)
