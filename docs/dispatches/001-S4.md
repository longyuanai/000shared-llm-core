### ISSUE 1 · SOCAdapter CLI 契约适配(SOC-CLI-001)

**目标**: 让 `python -m ai_soc_agent --input {...} --json` 能被 `JSONSubprocessAdapter` 调用,输出 `{findings: [...]}` JSON envelope。

**任务**:
1. 查 `src/ai_soc_agent/__main__.py`(或 cli.py)现状
2. 新增子命令 `python -m ai_soc_agent.cli scan --input <payload.json> --json`:
   - `--input` 接 JSON 字符串(SHMEM 也行,先 JSON)
   - `--json` 开关:开启时输出 JSON envelope,关闭时维持现有 CLI 行为
3. payload schema:`{"source": "sshd|evtx|nginx|okta", "events": [...]}` 或现有日志路径
4. 输出 envelope:
```json
{
  "findings": [
    {"id": "soc-001", "severity": "high", "confidence": 0.92,
     "title": "Brute force 5/min from 1.2.3.4", "host": "1.2.3.4", "ts": "..."}
  ]
}
```
   - 字段对齐 `Finding.from_dict`:必备 `id / severity / confidence / title`,可选 `host / ts / narrative / cve`
